One short funny line answering a prompt — the excuse a robot vacuum gives after eating a sock — for make.fun's "One-Liner Laugh Lab" bounty, $2.50 in USDC. The entry program writes the line to `/output/entry.txt`, where the house judge reads it.

> I didn't eat the sock. I promoted it: it's middle management in my dustbin now.

## Run it

```sh
python3 main.py
```
